# Приложение Career Advisor

Обзор и установка: [главный README](../README.md). Понятное объяснение реализации: [архитектура](../docs/ARCHITECTURE.md). Продуктовые критерии: [ТЗ](../docs/PRODUCT_SPEC.md).

В этом каталоге находятся действующий сервер, интерфейс, демо и тесты. Старые CLI/Telegram-прототипы в опубликованную версию не входят.

## Запуск

Проверенное окружение — Python 3.14 на macOS. Находясь в этом каталоге:

```sh
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-tested.txt
python -m uvicorn web_app:app --host 127.0.0.1 --port 8766 --no-access-log
```

Откройте http://127.0.0.1:8766/. Используйте один процесс; несколько workers не поддерживают общую локальную очередь AI. Демо работает без провайдеров. Для остановки — Control + C.

## Настройки

`app_config.py` загружает `final/.env`, затем существующий `.env` родительского каталога. Переменные, уже заданные в окружении, имеют приоритет. Секреты не должны попадать в Git.

| Переменная | Назначение |
| --- | --- |
| `GIGACHAT_CREDENTIALS` | Ключ авторизации GigaChat |
| `GIGACHAT_MODEL` | Доступная аккаунту модель; значение примера не гарантирует доступность на другом аккаунте |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS`, `GIGACHAT_API_B2B` либо `GIGACHAT_API_CORP` |
| `GIGACHAT_MAX_TOKENS` | Бюджет ответа: от 256 до 8000; по умолчанию 3000 |
| `GIGACHAT_VERIFY_SSL_CERTS` | Проверка сертификатов; оставьте включённой |
| `GIGACHAT_CA_BUNDLE` | При необходимости путь к доверенному PEM-файлу центра сертификации |
| `TAVILY_API_KEY` | Поиск и извлечение публичных страниц |
| `SBER21_DB` | Необязательный путь к базе; по умолчанию `data/career.sqlite3` |

Модель использует одну общую очередь процесса. Ожидание доступа ограничено 10 секундами, таймаут SDK модели — 60 секундами. Авторизация и внутренние повторы SDK могут увеличивать общее время ответа. Приложение не повторяет весь платный сценарий автоматически.

Трассировка запросов во внешний сервис не нужна для обычного запуска. Перед включением LangSmith или аналогичной системы проверьте, какие резюме, ответы и ключи она может получить.

## Хранение

`Application` сериализуется в JSON. SQLite содержит последнее состояние, полные снимки версий и краткие статусы операций. База создаётся при первом использовании. Оригинальный PDF не хранится; извлечённый текст и версии документов сохраняются.

Изменение профиля/вакансии сбрасывает зависимые результаты. Ответы интервью сбрасывают сравнение и документы; повторный анализ — адаптацию и документы. Новое исследование сбрасывает подтверждение письма. История остаётся доступной.

## API

Документация локального API — http://127.0.0.1:8766/docs. Команды изменения содержат актуальный `version`.

| Путь после `/api/applications/{id}` | Метод | Действие |
| --- | --- | --- |
| `/resume-upload?version=N` | POST multipart | Извлечь PDF |
| `/resume-source`, `/profile` | PUT | Сохранить исходник / подтвердить профиль |
| `/profile-extract` | POST | Разобрать факты через AI |
| `/vacancy-source`, `/vacancy` | PUT | Сохранить текст / подтвердить требования |
| `/vacancy-fetch`, `/vacancy-extract` | POST | Получить страницу / разобрать требования |
| `/match` | POST | Выполнить сравнение заново |
| `/match-review` | PUT | Сохранить ручной вывод по требованию |
| `/interview` | PUT | Подтвердить ответы или пропустить |
| `/changes` | POST / PUT | Предложить правки / сохранить решения |
| `/resume-assemble` | POST | Собрать резюме из фактов и принятых правок |
| `/resume`, `/letter` | PUT | Сохранить либо подтвердить документ |
| `/letter-generate` | POST | Подготовить письмо |
| `/research` | POST | Исследовать компанию; `website`, `reuse_sources` |
| `/versions`, `/restore` | GET / POST | История / восстановление |
| `/export/resume.pdf`, `/export/resume.docx`, `/export/letter.txt` | GET | Скачать подтверждённый документ |
| `/export/company.md` | GET | Скачать готовый отчёт о компании |

`GET /api/health` сообщает наличие локальных настроек без запросов провайдерам. Старые `/api/chat` и `/api/download/{token}` удалены как неиспользуемые текущим интерфейсом.

## Проверки

```sh
python -B -m unittest discover -s tests -q
python -m pip check
```

Проверки используют временные данные и подмены внешних запросов. Обновлённый протокол проверки: [VERIFICATION.md](VERIFICATION.md).

`requirements-tested.txt` — точный снимок зависимостей проверенного окружения, включая транзитивные. `requirements.txt` — допустимые диапазоны прямых зависимостей; это не обещание совместимости с произвольной ОС/Python.

## Границы защиты

- Включены проверка локального Host, отклонение межсайтовых изменений, CSP и запрет кэширования API.
- URL валидируются перед передачей Tavily; приложение не загружает страницы напрямую. Проверка DNS/редиректов при фактической загрузке остаётся на стороне провайдера.
- PDF читается отдельным процессом с лимитами. На macOS нет жёсткого лимита памяти этого процесса; действуют время, CPU и ограничения содержимого. Linux-лимит памяти реализован, но отдельно не проверен здесь.
- Не реализованы аккаунты, шифрование базы и изоляция пользователей. Исходную конфигурацию нельзя считать готовой к размещению в интернете.
