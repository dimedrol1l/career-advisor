# Самостоятельный запуск

## После получения репозитория

Открой Terminal. Перейди в корень скачанного проекта `career-advisor`, затем выполни:

```sh
cd final
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-tested.txt
python -m uvicorn web_app:app --host 127.0.0.1 --port 8766 --no-access-log
```

После сообщения `Uvicorn running on http://127.0.0.1:8766` открой **http://127.0.0.1:8766/**. Оставь терминал работающим. Отдельная сборка интерфейса не нужна.

При следующем запуске установка не требуется. Из `final`:

```sh
source .venv/bin/activate
python -m uvicorn web_app:app --host 127.0.0.1 --port 8766 --no-access-log
```

Для остановки нажми **Control + C** в том же терминале. Закрытие вкладки браузера сервер не останавливает.

## Существующая копия в папке portfolio

Если используешь уже настроенное общее окружение `portfolio/.venv`, перейди в `portfolio/Sber21/final` и запусти:

```sh
source ../../.venv/bin/activate
python -m uvicorn web_app:app --host 127.0.0.1 --port 8766 --no-access-log
```

Эта команда подходит для существующего расположения; после нового клонирования пользуйся отдельным `.venv` по инструкции выше.

## Демо и реальные запросы

«Попробовать демо» создаёт отдельный вымышленный отклик без обращения к AI. Прочитай соответствие, пропусти интервью, рассмотри готовую правку, собери и подтверди резюме, затем скачай документы.

Кнопки AI и поиска запускают настоящую обработку и расходуют лимиты. Для них заполни `.env` по `.env.example`. Существующий файл с ключами не заменяй; настройки читаются при запуске сервера.

## Где данные

База — `final/data/career.sqlite3`, если не задан другой путь `SBER21_DB`. Остановка и перезапуск её не удаляют. Сохраняются отклики, тексты документов и история. Ключи, база и локальные документы не входят в репозиторий.

## Если не запускается

- `No module named uvicorn`: проверь активацию нужного `.venv` и установи `requirements-tested.txt` в него.
- Порт занят: найди свой работающий сервер в другом терминале и останови Control + C. Либо укажи `--port 8767` и открой http://127.0.0.1:8767/.
- AI не настроен: проверь названия переменных в `.env`, доступность модели и перезапусти сервер. Демо можно продолжить без ключей.
- Сайт вакансии недоступен: вставь текст вручную.
- PDF не читается: нужен текстовый слой; можно вставить текст резюме вручную.

## Проверить изменение кода

Из `final` с активированным окружением:

```sh
python -B -m unittest discover -s tests -q
python -m pip check
```

Тесты не требуют ключей и не делают платных запросов. Начать чтение кода поможет [гайд по архитектуре](../docs/ARCHITECTURE.md).
